How to set up three new features

Step-by-step instructions for configuring currency per therapist, session types, and the client intake form.

🌐 thewellnesshub-eg.com Built by Raisin
1

Currency Per Therapist

Set each therapist's currency to EGP or USD. The system automatically shows prices in their currency. Default is EGP.

Where to configure

  1. Go to Users → All Users
  2. Click Edit on a therapist account
  3. Scroll to the Appointment Timezone section
  4. Find Your currency dropdown — directly below the timezone field
  5. Choose EGP or USD, then click Update Profile
Note: The currency dropdown only appears for therapist accounts (shop_staff role). Regular admin accounts won't see it.
Users → Edit Therapist → Appointment Timezone section

Who does what

Role Action
Admin Set currency once per therapist. A Currency column also appears in the Users list.
Therapist No action needed — ask admin if the currency is wrong.
Client Prices show automatically in the therapist's currency.
2

Session Types & Durations

Offer multiple session options per product — each with its own label, duration, and dual-currency price. Clients choose from a dropdown on the booking page.

Where to configure

  1. Go to Products → All Products
  2. Click Edit on any Appointment product
  3. In the Product Data panel, stay on the General tab
  4. Scroll to the Wellness Product section
  5. Check ☑ Enable Duration Options
  6. Click + Add Duration Option and fill each row: Label, Duration (minutes), EGP Price, USD Price
  7. Click Update to save
Blank fields use the product's original settings:
· Leave Duration blank → uses the product's default duration
· Leave EGP Price or USD Price blank → uses the product's original price for that currency
Products → Edit → General tab → Wellness Product section
Check the checkbox to enable Session type Options
Add Session Type Options as needed

Location What's shown
Booking page Session Type dropdown before the calendar — price updates on selection
Cart & Checkout Session type next to the product name
Order details Visible to both client and admin
Email notifications Included in all 6 appointment email templates
3

Client Intake Form

New clients fill a health & contact form during checkout. Appears only for first-time clients — matched by email address. Returning clients skip straight to payment.

How it decides who's new:
🆕 Email with no past orders → full 7-step checkout
🔁 Email with any previous order → skips to payment (Step 1 → Step 7)
✏️ Same person, different email → treated as new

Where to view submitted forms

  1. Go to Appointments → Intake Forms in the left sidebar
  2. Browse all forms — each tied to a client email address
  3. Click any entry to see all 27 fields in detail
Appointments → Intake Forms — view all submitted client intake forms

Who sees what

Role What to expect
Admin Full intake form list under Appointments → Intake Forms. Summary card on each order page.
Therapist Intake summary included in New Appointment emails. Browse all forms under Appointments → Intake Forms.
Client New clients complete Steps 2–6 at checkout. Returning clients skip to payment. No login needed — matched by email.
