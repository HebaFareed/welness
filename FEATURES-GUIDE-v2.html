How to set up three new features

Step-by-step instructions for configuring currency per therapist, session types, and the client intake form.

🌐 thewellnesshub-eg.com Built by Raisin
1

Currency Per Therapist

Set each therapist's currency to EGP or USD. Prices display automatically. Default is EGP.

Where to configure

  1. Go to Users → All Users
  2. Click Edit on a therapist
  3. Scroll to Appointment Timezone
  4. Find Your currency — below the timezone field
  5. Choose EGP or USD, click Update Profile
Note: Only appears for therapist accounts (shop_staff role).
Users → Edit Therapist → Appointment Timezone

2

Session Types & Durations

Offer multiple session options per product with custom labels, durations, and dual-currency pricing.

Where to configure

  1. Go to Products → All Products
  2. Click Edit on an Appointment product
  3. In Product Data → General, scroll to Wellness Product
  4. Check ☑ Enable Duration Options
  5. Click + Add Duration Option, fill Label / Duration / EGP / USD
  6. Click Update to save
Blank = fallback: Empty duration uses product default. Empty price uses original.
Products → Edit → General → Wellness Product

3

Client Intake Form

First-time clients complete a health & contact form. Appears only for emails with no previous orders. Returning clients skip to payment. No login needed.

New: 🆕 Email with no past orders → full 7 steps · 🔁 Email with orders → skips to payment · ✏️ Different email → treated as new
